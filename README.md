## 通用快速开始

STM32 项目均基于 Keil MDK-ARM + STM32CubeMX 开发：

1. 克隆本仓库：`git clone https://github.com/aka-mtjfj/electronic-circuit.git`；
2. 进入项目目录下的 `MDK-ARM`，用 Keil 打开 `.uvprojx` 工程文件；
3. 如需修改外设配置，可用 CubeMX 打开项目根目录的 `.ioc` 文件；
4. 编译并下载至目标开发板。

FPGA 项目的编译方式见项目七说明。

## 项目一：远程灌溉机

微处理器项目设计课程的小组作业（84 组）。系统采集环境信息，接受云端或安卓上位机的远程指令，控制执行机构完成灌溉动作，适合作为物联网灌溉场景的原型验证。

### 功能特性

- DHT11 采集温湿度，TCS34725 识别环境颜色，VL6180X 激光测距；
- 舵机与电机驱动，控制出水口动作；
- L610 4G 模组接入华为云，也可通过串口连接安卓上位机；
- OLED 实时反馈系统状态与指令执行结果；
- 五键密码输入面板（数字 1-4 与删除键）完成开机鉴权。

### 工作原理

上电初始化后，MCU 驱动 L610 完成 4G 入网与华为云连接；随后通过密码面板鉴权。鉴权通过后进入指令循环：接收云端或上位机指令，调用对应传感器或执行机构，将采集与执行结果经 OLED 反馈，同时回传云端。

### 硬件清单

- 主控：STM32F411RE 开发板；
- 通信：L610 4G 模组（含电话卡）、拨码开关；
- 传感器：DHT11、TCS34725 颜色传感器、VL6180X 激光测距模块；
- 执行：舵机、电机与水泵机构；
- 交互：OLED（I2C）、五键输入面板；
- 电源：外置 5V 电源。

### 使用方法

1. 外接 5V 电源上电，屏幕显示 `Machine Init...`；
2. 将 L610 拨码开关拨到中间，等待三个连接步骤完成；
3. 按屏幕提示输入密码 `1234`，输错可按第五个键删除上一位；
4. 通过安卓上位机或华为云下发指令，MCU 执行并在 OLED 上反馈。

### 常见问题

- 下载代码时需改变 U5V 跳线帽位置；
- 屏幕持续显示 `Cmd Error2`，多为上位机串口线松动，重新插紧即可；
- L610 内置流量卡可能不可用，需更换电话卡，实测部分电话卡亦存在兼容问题；
- 颜色传感器的默认颜色随环境光变化，需按现场环境调整判据。

详细接口分布与机械板原理图见 `F411RE/说明.docx`。

## 项目二：无线音频收发系统

个人独立完成的无线通信工程设计。发送端采样音频信号经 NRF24L01 无线发出，接收端还原播放，验证了"采样—无线传输—还原"完整链路的可行性。

### 功能特性

- ADC 实时采样音频信号，NRF24L01 分包无线发送；
- 接收端通过 DAC 还原音频并播放；
- OLED 显示收发状态，按键切换收发模式；
- 附音频收发模块原理图（PDF），便于硬件复现。

### 工作原理

发送端：ADC 对音频输入等间隔采样 → 缓存打包 → NRF24L01 定时发送；
接收端：NRF24L01 接收数据包 → 校验组包 → DAC 按采样节拍输出，经功放播放。

### 硬件清单

- 主控：STM32F3 系列开发板（收发各一块）；
- 无线：NRF24L01 模块两块；
- 音频：麦克风输入电路与功放输出电路；
- 交互：OLED、按键。

### 当前状态

工程为初版，实测传输噪声较大。已定位的可能原因包括采样率与播放节拍不完全匹配、数据分包策略简单以及电源纹波干扰，音质优化是后续主要改进方向。

## 项目三：无线模块收发测试

NRF24L01 的驱动验证工程，是项目二的前置实验：按键每按下一次，发送端更改一次数值并发出，接收端经 OLED 显示收到的数据，用于确认无线链路与参数配置正确。

### 使用要点

- 收发双方需匹配通信速率、信道等参数与接收地址；
- 模块接线对照引脚接口图连接；
- 按键接 PB0，配置为下拉输入。

详细说明见 `NRF24L01/说明.docx`。

## 项目四：PID 电机定速控制

电机控制基础项目：以编码器测得的实际转速为反馈，与目标转速比较后经 PID 运算调节 PWM 占空比，使单电机在负载波动下仍保持恒速。

### 功能特性

- 编码器实时测速，PID 闭环调节 PWM 占空比；
- 按键设定目标转速，OLED 显示当前转速与运行状态；
- 含 ADC+DMA 与串口模块，便于拓展采集与调试输出。

### 控制流程

编码器脉冲计数得到当前转速 → 与目标转速求偏差 → PID 计算控制量 → 更新 PWM 占空比 → 循环执行直至转速稳定。

## 项目五：FFT 频谱分析

基于 STM32F103C8T6 的 DSP 实验项目：对外部正弦信号（0-10kHz 范围）等间隔采样，调用 ST DSP 库完成 FFT 运算，将频谱结果显示在 OLED 上，直观展示离散傅里叶变换的效果。

### 功能特性

- ADC+DMA 连续采样，保证采样等间隔；
- 调用 DSP 库完成 FFT 运算；
- OLED 显示各频率分量的幅值分布。

## 项目七：FPGA 超声波测距

基于 EGO1 开发板与 HC-SR04 超声波模块的测距项目，采用模块化 Verilog 设计，各子模块功能单一、接口清晰，并配有独立仿真。

### 系统架构

| 模块 | 功能 |
| --- | --- |
| `ultrasound_meter.v` | 顶层模块，完成各子模块例化与连接 |
| `ultrasound_ctrl.v` | 产生驱动时序，测量回波并计算距离 |
| `ave_filter.v` | 均值滤波，抑制测距抖动 |
| `bin_to_bcd.v` | 二进制结果转 8421 BCD 码 |
| `nixie_display.v` | 数码管扫描显示 |
| `beep_led_alarm.v` | 按距离阈值驱动蜂鸣器与 LED 报警 |

### 快速开始

1. 用 Vivado 打开 `ultrasound_meter.xpr` 工程文件；
2. 可先运行 `ultrasound_meter.srcs\sim_1` 下的各模块 testbench 进行仿真验证；
3. 综合、实现后下载至 EGO1 开发板，连接 HC-SR04 模块即可测距。

### 设计文档

`doc` 目录包含 HC-SR04 模块说明书、EGO1 电路图、设计框图（Visio）与汇报 PPT。
